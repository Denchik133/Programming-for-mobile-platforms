
# Дизайн-система Widget Store

## 1. Загальна концепція

Інтерфейс Widget Store створено на основі Material Design 3. Він використовує світлу тему, фіолетовий основний колір, картки товарів і повторно використовувані Flutter-віджети.

## 2. Кольорова палітра

| Назва | HEX | Призначення |
|---|---|---|
| Primary | `#6750A4` | Основні кнопки та акценти |
| Secondary | `#625B71` | Другорядні елементи |
| Background | `#F8F7FC` | Фон застосунку |
| Surface | `#FFFFFF` | Картки та поверхні |
| Text Primary | `#1D1B20` | Основний текст |
| Text Secondary | `#625B71` | Другорядний текст |
| Success | `#2E7D32` | Успішні стани |
| Error | `#B3261E` | Помилки |

## 3. Компоненти

- `ProfileWidget` — картка профілю користувача.
- `CustomButton` — кнопка з варіантами оформлення та станом завантаження.
- `AnimatedCounter` — лічильник зі зміною значення та анімацією.
- `ProductCard` — картка товару з анімацією зображення, обраним і додаванням до кошика.

## 4. Принципи адаптивності

- Використання прокручування для довгого вмісту.
- Використання сітки для каталогу товарів.
- Застосування стандартних компонентів Material 3.
- Повторне використання власних віджетів для узгодженого оформлення.

## 5. Figma

Макет дизайн-системи у Figma потрібно створити окремо. Після створення тут слід додати посилання на файл Figma.
