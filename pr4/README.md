# Практична робота №4. Основи мови Dart

## Мета роботи

Ознайомитися з основами мови програмування Dart, типами даних, функціями, об'єктно-орієнтованим програмуванням, колекціями та асинхронними операціями. Навчитися створювати консольні застосунки, працювати з JSON-файлами та тестувати програмний код.

## Технології

- Dart SDK 3.13.2 або сумісна версія згідно з `pubspec.yaml`.
- Пакет `test` для модульного тестування.
- Пакет `lints` для статичного аналізу коду.
- JSON для збереження та обміну даними.

## Виконані завдання

### Завдання 1. Змінні та типи даних

Реалізовано приклади використання типів `int`, `double`, `num`, `String` і `bool`. Продемонстровано математичні операції, перетворення типів, роботу з рядками, колекціями `List`, `Set`, `Map`, логічними операторами, умовними виразами, `late` та `null safety`.

Файл: `bin/task1_variables.dart`.

### Завдання 2. Функції

Створено функції для обчислення суми та середнього значення, форматування імені, обчислення факторіала й чисел Фібоначчі. Продемонстровано анонімні функції, замикання та методи `map`, `where`, `fold`.

Файл: `bin/task2_functions.dart`.

### Завдання 3. Об'єктно-орієнтоване програмування

Реалізовано класи `Student`, `Course`, `Person`, `Professor` та `University`. Продемонстровано наслідування, абстрактний клас, гетери, роботу з оцінками, запис студентів на курси, перевірку передумов, пошук і формування статистики. Реалізовано перетворення даних студента в JSON і відновлення об'єкта з JSON.

Файли: `lib/models/` і `bin/task3_classes.dart`.

### Завдання 4. Робота з колекціями

Реалізовано фільтрацію парних чисел, підрахунок частоти слів, сортування студентів за середнім балом, пошук унікальних навичок, визначення спільних курсів, групування студентів за роком народження та обчислення середніх оцінок за курсами.

Файл: `bin/task4_collections.dart`.

Додатково створено клас `Calculator` для арифметичних операцій та обчислення середнього значення.

Файл: `lib/utils/calculator.dart`.

### Завдання 5. Асинхронне програмування

Реалізовано асинхронне отримання даних за допомогою `Future`, паралельне виконання операцій через `Future.wait`, збереження та завантаження студентів у JSON-файлі, потік даних `Stream`, обробку помилок і тайм-аутів.

Файли: `lib/utils/async_service.dart` і `bin/task5_async.dart`.

## Встановлення та запуск

Переконайтеся, що Dart SDK встановлений і доступний у терміналі. Перейдіть до кореневої папки практичної роботи:

```bash
cd pr4
```

Встановіть залежності:

```bash
dart pub get
```

Запускайте окремі завдання командами:

```bash
dart run bin/task1_variables.dart
dart run bin/task2_functions.dart
dart run bin/task3_classes.dart
dart run bin/task4_collections.dart
dart run bin/task5_async.dart
```

П'яте завдання створює або оновлює файл `data/students.json`.

## Перевірка та тестування

Для статичного аналізу виконайте:

```bash
dart analyze
```

Для запуску всіх модульних тестів:

```bash
dart test
```

Тести охоплюють моделі університетської системи, валідацію оцінок, запис на курси, арифметичні операції та окремі функції обробки колекцій.

## Результат

Створено п'ять консольних програм, моделі університетської системи, утиліти для обробки даних, калькулятор, сервіс асинхронної роботи з JSON та модульні тести. Проєкт демонструє основні можливості Dart і принципи побудови структурованого програмного забезпечення.
