# Практична робота №10 (Частина 1)
## Збереження даних у файловій системі

### Варіант 3. Менеджер нотаток

## 1. Мета роботи

Ознайомитися зі способами збереження та обробки даних у файловій системі мобільного застосунку за допомогою Flutter і Dart. Реалізувати застосунок для створення, перегляду, редагування, видалення та пошуку нотаток із використанням JSON-файлів.

## 2. Опис застосунку

У межах практичної роботи розроблено мобільний застосунок **«Менеджер нотаток»**, який дає змогу зберігати текстові нотатки у файловій системі пристрою.

Кожна нотатка зберігається в окремому JSON-файлі. Для роботи з файловою системою використовується пакет `path_provider`, який забезпечує отримання шляху до внутрішнього каталогу документів застосунку.

## 3. Функціональні можливості

Реалізовано такі можливості:

- **Створення нотаток** — додавання нової нотатки із заголовком і текстом.
- **Перегляд нотаток** — відображення списку збережених нотаток.
- **Редагування** — зміна заголовка та вмісту нотатки.
- **Видалення** — видалення непотрібних нотаток.
- **Перейменування** — зміна назви нотатки та відповідного імені файлу.
- **Пошук** — пошук за заголовком або вмістом.
- **Фільтрація за датою** — відображення нотаток, змінених у вибраний день.
- **Перегляд інформації про файл** — відображення дати останньої зміни та розміру файлу.
- **Експорт у JSON** — створення окремого JSON-файлу з даними вибраної нотатки.

## 4. Структура проєкту

Основні файли та каталоги:

```text
lib/
├── models/
│   └── note.dart
├── services/
│   └── notes_file_manager.dart
├── screens/
│   └── home_screen.dart
└── main.dart

test/
└── widget_test.dart
```

Призначення основних компонентів:

- `note.dart` — модель нотатки, яка містить назву файлу, заголовок, вміст, дату останньої зміни та розмір.
- `notes_file_manager.dart` — реалізація операцій із файловою системою: створення, читання, редагування, видалення, перейменування, пошук, фільтрація та експорт.
- `home_screen.dart` — головний екран застосунку з інтерфейсом для керування нотатками.
- `main.dart` — точка входу в застосунок і налаштування головного інтерфейсу.
- `widget_test.dart` — тест для перевірки відображення основних елементів інтерфейсу.

## 5. Використані технології

- **Flutter** — розробка інтерфейсу мобільного застосунку.
- **Dart** — мова програмування.
- **path_provider** — отримання шляху до внутрішнього каталогу документів застосунку.
- **dart:io** — робота з файлами та каталогами.
- **dart:convert** — кодування та декодування JSON.

## 6. Збереження даних

Для зберігання нотаток використовується внутрішній каталог документів застосунку, отриманий за допомогою `getApplicationDocumentsDirectory()`.

Усередині нього створюється каталог `notes`, де розміщуються JSON-файли нотаток.

Кожен файл містить такі дані:

- `title` — заголовок нотатки;
- `content` — текст нотатки;
- `lastModified` — дата та час останньої зміни.

Розмір файлу визначається під час його читання. Для експорту формується окремий JSON-файл із додатковою інформацією про розмір.

## 7. Запуск проєкту

Для запуску застосунку необхідно:

1. Відкрити кореневу папку проєкту в терміналі.
2. Встановити залежності:

```bash
flutter pub get
```

3. Запустити застосунок на підключеному пристрої або емуляторі:

```bash
flutter run
```

Для запуску тестів використовується команда:

```bash
flutter test
```
